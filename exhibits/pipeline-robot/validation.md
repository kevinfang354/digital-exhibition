# V6 运动与交互检查

- 将V2展陈模型演化为前旋转单元、中间传动单元、后驱动单元的同一整机模型。前端3臂、中段2臂、后端3臂共16只轮子；所有轮胎增加可见滚动标记。前端旋转体连续自转；后轮随运动路径滚动；转向轴独立偏转，前端U形开口随之转动。
- 模型驱动关系：以80毫米名义接触半径和10度前轮倾角估算螺距88.6毫米/转；前端旋转角由累积行进距离推得。到T口暂歇时转数与机身位移共同停止；再次启动后前端与后轮各自按估计路径滚动。此模型不解算接触力、摩擦、传动轴扭矩或轮滑移。
- 展示预紧：自由轮中心半径69毫米、轮胎半径14毫米；压入80毫米管内时，初始弹簧收缩约3毫米。T形场景按每只轮胎的表面点取样，为每一弹性臂寻找最小可行压缩量。螺旋进入支管的采样阶段，前端至少2/3臂处于模型管壁接触约束。
- 几何抽样：60秒、每40毫秒，共1501姿态；16轮每只按32个周向角与两侧端面取样，未发现轮胎越出160毫米内径的主支管体积并集，全部支撑臂能够在模型设定行程内收回。不同臂的有限圆柱轮胎用支持函数沿候选分离轴筛查，所有受检轮胎对有正向分离；最小模型投影间隔约29.5毫米。每500毫秒抽样非线缆网格，无超过0.8毫米的管壁越界。该记录只对应展示几何和抽样姿态，不构成连续碰撞认证或实机毫米净空。
- 交互抽样：真实Three.js几何配合模拟DOM验证打开展台、播放、暂停、时间轴定位、逐阶段、跟随前端近景、复位、切换越障与关闭；静态资源、语法、GLB长度与节点已检查。软件兼容渲染作过关键姿态图像检查。无可用浏览器可执行程序，未进行真实浏览器的目视帧检查。
- 视频边界：原始T管实验是外部视角，不透明T管遮挡内部接触状态；前端预紧及后轮滚动关系依据论文机构描述与用户纠正编排，不将视频遮挡的量写作观察或实测值。
