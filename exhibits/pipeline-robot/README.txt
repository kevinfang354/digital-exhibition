管内探索 · 管道机器人数字展品 V6

打开方式
1. 解压全部文件，在浏览器中打开 index.html。
2. 若浏览器限制本地视频或三维资源，请在本目录运行 python -m http.server 8000，再打开 http://localhost:8000。
3. 所有三维结构、T形支管转向、慢速越障和GLB下载都位于同一个“三维交互”展台。

T形分支演示
- 选择“T形分支转向”，点击“慢速播放”。完整动作60秒、五阶段：前端螺旋接近→停转并转向预紧→前端贴壁螺旋进入→后轮滚动支撑、机身跟进并反向调节→后轮进入支管并向上爬升。
- 前端3臂周向布置的倾斜滚轮随旋转体连续转动。自由伸长半径约69毫米（模型估计），置于内半径80毫米的示意管道后，轮胎半径14毫米使弹性臂约压缩3毫米；更多压缩由T形空间约束决定。演示展示预紧位置，不计算接触力。
- 前端的名义螺距以 R=80毫米、α=10度按2πRtan(α)得到约88.6毫米/转；将模型沿管道的位移与前端转数绑定。真实轮壁滑移、摩擦、载荷和螺距均未知。
- 后部驱动电机经传动轴驱动前旋转单元；后端为随运动滚动并支撑机身的被动轮组，模型没有额外添加未经资料证实的轮毂电机。后轮转数由后单元路径长度与轮径算出。展台中显示前端转数、前臂贴壁/模型压缩和后轮滚动转数；可暂停、拖动时间轴、逐阶段查看，或切换“跟随前端细节”近景。
- “凸台越障”仍以18秒演示弹性臂压缩与恢复，不模拟实际越障高度或轮壁受力。

资料与模型范围
- 论文稿件的整机名义长200毫米、轮径28毫米、前轮倾角10度，以及T管实验内径160毫米作为比例锚点。自由伸长半径、转向轴位置、弹簧行程与运动路径是可编辑的展陈估计；同名稿件的正式发表信息尚未确认。
- 视频能够观察样机进出不透明T管的顺序，不能直接确认内部每只轮子的接触、转数或后轮驱动形式。模型参考稿件原理图，并采用机械关系解释用户提出的前端预紧与后轮跟进。
- 下载的GLB为静态、未压缩的初始结构；动画保存在model-source.js与viewer.js。它不代替SolidWorks原生装配体或实机工程验证。
